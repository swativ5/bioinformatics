# Bioinformatics

This repo contains code, and solutions for the first two courses of the [**Bioinformatics Specialization**](https://www.coursera.org/specializations/bioinformatics) by the University of California, San Diego on Coursera.

I started this specialization partly to prove a point. [I believed that the Leaderboard Cyclopeptide Sequencing algorithm wouldn't work reliably with any simple heuristic, and I wanted to test that claim. By the time I reached Course 2, I learnt I was right. :)]

But eventually I just gave in to the fun of coding up small algorithms and seeing how that might affect different biological aspects. I ended up really enjoying the depth and the pacing of the course.

Though I’m stopping after the third course for now, I might return to complete the rest of the specialization later.

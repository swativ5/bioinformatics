# 1.1 Randomized Motif Search

## **1. Introduction to Randomized Motif Search**
- Randomized algorithms make decisions by flipping coins or rolling dice.
- Though it may seem counterintuitive, such algorithms can be effective, as demonstrated by Comte de Buffon’s needle experiment for approximating π.
- There are two types of randomized algorithms:
  - **Las Vegas algorithms**: Always return the correct solution but use randomness in computation.
  - **Monte Carlo algorithms**: Provide fast but approximate solutions, which can be refined through multiple runs.
- The **motif-finding algorithms** discussed in this chapter are Monte Carlo algorithms.

## **2. Defining Profile-Based Motif Search**
- **Profile(Motifs)**: A probability matrix built from a collection of k-mers.
- **Motifs(Profile, Dna)**: The set of most probable k-mers in Dna based on Profile.
- The method iterates:
  1. Start with a random collection of k-mers from Dna.
  2. Construct the profile matrix **Profile(Motifs)**.
  3. Use this profile to generate new k-mers, forming **Motifs(Profile(Motifs), Dna)**.
  4. Repeat the process while the score improves.

## **3. Randomized Motif Search Algorithm**
### **Steps:**
1. Select **k-mers** randomly from each string in **Dna**.
2. Initialize **BestMotifs** as the initial random motifs.
3. Iteratively:
   - Compute **Profile(Motifs)**.
   - Find the most probable motifs in **Dna** using the profile.
   - Update **BestMotifs** if the new motifs have a better score.
4. Stop when no further improvement is possible.
- Uses a **random number generator** to select the initial motifs.

## **4. Implementing Randomized Motif Search**
- **Input**: Integers k and t, followed by a set of DNA strings.
- **Output**: The best motifs found after running the algorithm **1,000 times**.
- **Key Considerations**:
  - Use **pseudocounts** to prevent zero probabilities.
  - Running the algorithm many times helps find better approximations.

## **5. Why Randomized Motif Search Works**
- Despite starting with a random guess, iterations refine the motifs.
- Example: Given an implanted (4,1)-motif **ACGT**, the algorithm starts with random selections but converges to the correct motif.
- Profile matrix updates improve motif selection probabilities.

## **6. Performance on the Subtle Motif Problem**
- Tested on an implanted **15-mer AAAAAAAAGGGGGGG**.
- After **100,000 runs**, it produced a consensus motif **AAAAAAAacaGGGG** with a score of **43**.
- The score is close to the optimal motif (score 40) and better than **GreedyMotifSearch** (score 41).
- **Key Advantage**: Can be run for **longer motifs** and refined through multiple iterations.

## **7. Key Takeaways**
- **RandomizedMotifSearch** is effective for finding motifs when exact algorithms struggle.
- Works well with **multiple iterations** to refine approximations.
- Particularly useful for **longer motifs**, outperforming GreedyMotifSearch in such cases.
- Success depends on **multiple runs** and careful selection of **k-mers**.

# 1.2 How Can a Randomized Algorithm Perform So Well?

## **Uniform Profile and Its Limitations**
- If the DNA strings in the dataset **Dna** were truly random, every nucleotide in selected k-mers would have equal probability (≈0.25).
- This would result in a **uniform profile matrix**, which is **useless for motif finding** since no particular motif would stand out.

## **Extreme Cases of Profile Matrices**
- **Best Case (Lucky Selection)**: If we randomly choose the correct implanted k-mers at the beginning, we get a **perfect profile matrix**, immediately leading to the motif.
- **Worst Case (Random Start)**: A uniform profile matrix provides no useful information.
- **Typical Case**: The actual profile matrix usually lies **between these extremes**, gradually pointing towards the correct motif.

## **How Does RandomizedMotifSearch Improve Over Time?**
- Initially, a random selection of k-mers is made.
- If the profile matrix **deviates from uniformity**, it **points towards an implanted motif** (e.g., ACGT in an example case).
- RandomizedMotifSearch **iterates and refines** the motif search, increasing the chance of finding the correct motif over time.

## **Why Does RandomizedMotifSearch Work Despite Randomness?**
- Even though DNA sequences may appear random, they contain **implanted motifs** that introduce a **statistical bias**.
- This bias **gradually moves the profile matrix away from uniformity** and toward the implanted motif.
- **Example**: If a randomly chosen k-mer (AGGT) **fully captures the motif**, it contributes more strongly to the profile than **partial matches** (GTCT or CCGG).

## **Probability of Capturing an Implanted Motif**
- Even though the probability of **randomly selecting all implanted motifs is low**, the probability of capturing **at least one implanted motif is significant**.

### **Exercise Question 1: Compute the probability that 10 randomly selected 15-mers from 10 600-nucleotide-long sequences capture at least one implanted 15-mer.** _(Allowable error: 0.000001)_

#### **Answer:**
Let’s define the probability of **not** selecting the implanted motif in a single sequence and use complementary probability to find the required probability.

1. Assume the implanted motif can start at **any of 600 - 15 + 1 = 586** positions in each sequence.
2. The probability of **choosing a random 15-mer that is NOT the implanted motif** in one sequence is:
   \[
   \frac{586 - 1}{586} = \frac{585}{586}
   \]
3. The probability of **choosing 10 random 15-mers that all miss the implanted motif** is:
   \[
   \left(\frac{585}{586}\right)^{10}
   \]
4. The probability of **capturing at least one implanted motif** is the complement:
   \[
   1 - \left(\frac{585}{586}\right)^{10}
   \]

**Computing the numerical value:**

\[
1 - \left(\frac{585}{586}\right)^{10} \approx 0.01694
\]

Thus, the probability of capturing at least **one** implanted motif is **≈0.01694 (or 1.694%)**.

---

## **Challenges in Randomized Motif Search**
- Capturing **one implanted motif** is often **not enough** to ensure convergence to the optimal motif.
- Since there are **many possible k-mer starting positions**, the **probability of fully reconstructing the motif remains small**.
- **Solution**: Running **RandomizedMotifSearch multiple times** increases the likelihood of detecting at least **one implanted motif**, creating a bias towards the correct motif.

## **Probability of Capturing Multiple Implanted Motifs**
- The probability of randomly selecting **multiple implanted motifs** is **lower than capturing just one**.

### **Exercise Question 2: Compute the probability that 10 randomly selected 15-mers from 10 600-nucleotide-long sequences capture at least two implanted 15-mers.** _(Allowable error: 0.000001)_

#### **Answer:**
We now extend the previous calculation to consider capturing at least **two** implanted motifs.

1. The probability of **selecting at least one implanted motif** was already computed as **≈0.01694**.
2. To find the probability of capturing at **least two implanted motifs**, we need to compute the probability of selecting **exactly one** motif and subtract it from the previous result.

Using binomial probability approximation:

\[
P(\text{exactly one implanted motif}) = 10 \times \frac{1}{586} \times \left(\frac{585}{586}\right)^9
\]

Computing the numerical value:

\[
10 \times \frac{1}{586} \times \left(\frac{585}{586}\right)^9 \approx 0.01669
\]

Thus, the probability of capturing **at least two implanted motifs** is:

\[
0.01694 - 0.01669 = 0.00025
\]

So, the probability of capturing at least **two** implanted motifs is **≈0.00025 (or 0.025%)**.

---

## **Final Summary**
- A **uniform profile matrix** is **useless** for motif finding.
- **RandomizedMotifSearch refines motifs** over iterations.
- The presence of **implanted motifs creates a statistical bias**, helping the algorithm move towards the correct solution.
- The **probability of capturing at least one implanted motif is 1.694%**, while the probability of capturing **at least two motifs is 0.025%**.
- Running the algorithm **multiple times** increases the chances of success.

# Gibbs Sampling: Summary

## **Introduction**
- **GibbsSampler** is an iterative algorithm for motif finding that cautiously modifies a single k-mer at a time.
- It contrasts **RandomizedMotifSearch**, which may replace all k-mers in a single iteration.
- The algorithm explores motif space in a more controlled manner, reducing the risk of discarding good motifs.

## **Algorithm Overview**
- Starts with randomly selected k-mers from each of the **t** DNA sequences.
- At each iteration, a random integer **i** is selected between **1 and t**, and only the corresponding k-mer **Motifi** is changed.
- Uses a **random number generator** to decide whether to keep or replace a motif based on computed probabilities.

## **Random Number Generator in GibbsSampler**
- Requires an advanced **random number generator** that models an **n-sided biased die**.
- If given probabilities **(p1, …, pn)**, the generator selects an integer **i** with probability **pi**.
- If the values **(p1, …, pn)** do not sum to **1**, they are normalized by dividing each **pi** by their sum **C**.

## **Profile-randomly Generated k-mer**
- Unlike **Profile-most probable k-mer**, GibbsSampler selects a **Profile-randomly generated k-mer**.
- Probability **Pr(Pattern | Profile)** is computed for each k-mer in a string.
- Uses a random number generator to select one k-mer based on computed probabilities.

## **Pseudocode for GibbsSampler**
```
GibbsSampler(Dna, k, t, N)
    randomly select k-mers Motifs = (Motif1, …, Motift) from Dna
    BestMotifs ← Motifs
    for j ← 1 to N
        i ← Random(t)
        Profile ← profile matrix from all strings in Motifs except Motifi
        Motifi ← Profile-randomly generated k-mer in the i-th sequence
        if Score(Motifs) < Score(BestMotifs)
            BestMotifs ← Motifs
    return BestMotifs
```
- Unlike **RandomizedMotifSearch**, GibbsSampler can move from a **lower** to a **higher scoring** motif, allowing it to escape local optima.

## **Step-by-step Execution Example**
1. Randomly selects 4-mers.
2. Selects a string to be ignored temporarily.
3. Constructs motif, count, and profile matrices.
4. Computes **Profile-randomly generated k-mer** for the ignored string.
5. Uses **pseudocounts** to avoid zero probabilities.
6. Replaces the k-mer in the ignored string with the new **Profile-randomly generated k-mer**.
7. Repeats for other strings, updating motif matrices iteratively.
8. Algorithm **gradually converges** to the implanted motifs.

## **Challenges and Limitations**
- **Local Optima**: The algorithm may get trapped in a suboptimal solution instead of finding the globally optimal motif.
- **Multiple Runs Required**: Running GibbsSampler multiple times with different random initializations increases the likelihood of finding the best motifs.
- **Pseudocounts Are Essential**: Without them, motifs with zero probabilities may lead to incorrect results.

## **Empirical Performance**
- Running GibbsSampler **2,000 times** on a dataset with an implanted **15-mer** motif **(AAAAAAAAGGGGGGG)** resulted in:
  - **Consensus motif: AAAAAAgAGGGGGGt**
  - **Score: 38** (which is lower than the expected 40, showing slight inaccuracies).

## **Code Challenge**
- **Input**: Integers **k, t, N**, followed by a space-separated list of DNA sequences.
- **Output**: The best motifs obtained from **20 random starts** of **GibbsSampler(Dna, k, t, N)**.
- **Sample Input & Output:**
  ```
  Input:
  8 5 100
  CGCCCCTCTCGGGGGTGTTCAGTAACCGGCCA GGGCGAGGTATGTGTAAGTGCCAAGGTGCCAG TAGTACCGAGACCGAAAGAAGTATACAGGCGT TAGATCAAGTTTCAGGTGCACGTCGGTGAACC AATCCACCAGCTCCACGTGCAATGTTGGCCTA

  Output:
  TCTCGGGG CCAAGGTG TACAGGCG TTCAGGTG TCCACGTG
  ```
- **Key Consideration**: Use **pseudocounts** to ensure robustness in motif selection.

# 1.4 Epilogue: How Does Tuberculosis Hibernate?

1. **Tuberculosis Overview**
   - Caused by *Mycobacterium tuberculosis* (MTB).
   - Over a million deaths per year.
   - Antibiotic-resistant strains are emerging.
   - One-third of the global population has a latent MTB infection.
   - Latent MTB remains dormant and may reactivate later.

2. **Latency and Survival Mechanisms**
   - MTB can stay latent for decades.
   - Resistance to antibiotics suggests it can shut down most gene expressions.
   - This dormancy is similar to bacterial sporulation.
   - Hypoxia (low oxygen levels) is associated with latent TB.
   - MTB adapts to hypoxia by regulating gene expression.

3. **Dormancy Survival Regulator (DosR) Discovery**
   - Identified in 2003 as a key transcription factor.
   - Controls multiple genes under hypoxic conditions.
   - Unclear how DosR regulates genes and binds to DNA.

4. **Motif Discovery for DosR Binding Site**
   - DNA array experiment identified 25 genes affected by DosR.
   - Researchers selected 10 genes (DosR dataset) for motif discovery.
   - Aim: Identify a hidden motif that DosR uses for gene regulation.

5. **Computational Analysis of DosR Motif**
   - **MedianString & RandomizedMotifSearch** tested with k = 8 to 12.
   - Identified possible consensus sequences:
     - MedianString: **GGACTTCCGGCC** (score 23)
     - RandomizedMotifSearch: **GGACCAACGGCC** (score 28)
   - RandomizedMotifSearch found a longer 20-mer motif:
     - **CGGGACCTACGTCCCTAGCC** (score 57)
   - **GibbsSampler** (2000 runs, N=200) found the same 20-mer motif but with a lower score (55).

6. **Final Challenge: Finding All DosR Binding Sites**
   - Different motif-finding algorithms produce slightly different results.
   - Task: Identify all DosR binding sites in MTB and the genes they regulate.
   - Upstream regions of 10 genes from the Park et al. (2003) study provided for analysis.
